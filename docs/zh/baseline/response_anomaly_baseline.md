# 推理异常检测工具性能基线报告

## 环境信息

CPU：Apple M5 Max（18 核 CPU，单进程 CPU）

内存：128 GB

Python：3.11.15

NumPy：2.4.6

测试词表：合成 ByteLevel BPE 词表（`vocab_size = 151,643`，对齐主流大语言模型词表规模）

本基线为推理异常检测工具在默认模式（纯Token序列）下的性能参考基线。以下场景的性能基线测试数据均为多次测试统计结果，实际运行时性能数据可能会根据硬件配置与环境状态稍有浮动。

## 初始化耗时与内存占用参考基线

该基线为默认模式（纯Token序列）下首次加载词表（冷启动）、同进程命中缓存复用（热启动）的耗时及驻留内存增量参考基线。

| 指标 | 实测值 | 说明 |
| :--- | :--- | :--- |
| **冷启动 `ILLDetector(tokenizer.json)`** | `12,552.1 ms`（约 `12.6 s`） | 首次解析 15.1 万词表并构建生僻字与重复检测查表数组 |
| **热启动 `ILLDetector(tokenizer.json)`** | p50 `0.091 ms` / p95 `0.106 ms` | 同进程命中词表缓存 |
| **驻留内存增量（`tracemalloc`）** | `15.27 MB` | 含首次加载共享打分模型（单份词表查表约 `12.23 MB`），构建期峰值 `54.51 MB` |
